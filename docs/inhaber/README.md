# Unterlagen für den Inhaber

Stand: 2026-10-14 · Ausbau „Bewerber-Maschine“ (ROADMAP §15)

Hier liegt alles, was der Betrieb selbst erledigen oder beantworten muss, fertig zum Abarbeiten oder Kopieren. Technischer Hintergrund steht in `docs/operations/`, Entscheidungen in `_relaunch/ENTSCHEIDUNGEN.md`.

| Dokument | Inhalt |
|---|---|
| [`checkliste-offsite.md`](checkliste-offsite.md) | Schritt für Schritt: Search Console, Bing, Arbeitsagentur, HWK-Lehrstellenbörse, Google-Unternehmensprofil, Kununu, lokale Links und Pressemitteilung „100 Jahre“ |
| [`bosch-anfrage.md`](bosch-anfrage.md) | Fertige Anfrage an Bosch (Klimahelden Schmiede bzw. Außendienst) und kurz an Buderus: Urkunde, Badge, Erlaubnis für die Zeichnungen, CAD-Daten, Recruiting-Paket, Fachbetriebssuche |
| [`ticket-hauptdomain.md`](ticket-hauptdomain.md) | Fertiger Ticket-Text für den Dienstleister von bad-energie.de: Weiterleitungen, Canonical-Fehler, „Karriere“ im Menü, robots.txt |
| [`offene-angaben.md`](offene-angaben.md) | Kurzliste aller offenen Angaben mit dem, was sie freischalten |

Regeln für alles, was außerhalb der Website über den Betrieb geschrieben wird: nur Belegtes, kein Euro-Betrag (Lohn auf Anfrage), keine festen Uhrzeiten, „Premium Partner“ erst mit Urkunde. Einzelheiten in `checkliste-offsite.md`.
